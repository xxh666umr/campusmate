# 验收演示脚本（5–8 分钟）

> 目标：在老师面前完整展示六个节点 + 创新点，避免临场找不到入口。
> 启动：双击 `start.bat`（会自动拉起 MySQL 并打开浏览器）；或先启动 MySQL，再运行 `php -S 127.0.0.1:8899 -t public public/index.php`。

---

## 0. 开场（20 秒）

“我做的是一个校园智能客服系统「智服」，用 PHP 8 + PDO + 原生 JS 实现，接入了讯飞星火大模型，并准备了本地演示引擎，断网也能完整演示。”

打开 <http://127.0.0.1:8899/login>，指出左侧三种咨询方式与右侧演示账号。

---

## 1. 登录与权限（40 秒）

1. 用 `student / student123` 登录 → 进入工作台。
2. 说明侧边栏：普通用户只能看到「智能客服 / 咨询历史 / 我的工单」。
3. 直接在地址栏访问 `/admin/users` → 显示 403「没有权限」。
   - 强调：不是前端隐藏菜单，服务端 `Auth::requireRole` 拦截，并写入 warning 日志。

---

## 2. 三种咨询方式（2 分钟）

### ① 单轮问答（20 秒）

输入：`选课冲突了怎么办？`
- 指出回答下方的「依据 · 教务教学 / 选课时间与三轮选课规则」——回答有知识库来源。
- 指出右下「有帮助 / 评价 / 转人工」与推荐追问。

### ② 多轮对话（40 秒）

1. 切到「多轮对话」。
2. 输入：`校园网一直认证失败`
3. 继续输入：`那还是不行怎么办`
- 指出回答以「接着刚才的问题继续看」开头，说明上下文生效。
- 说明单轮模式不会带上下文，这是两者的区别。

### ③ 信息选择（40 秒）

1. 切到「信息选择」→ 点「校园网络」→ 点「校园网认证失败 / 频繁掉线」。
2. 展示结构化的「原因 → 推荐步骤 → 小贴士 → 办理入口」。
3. 点「没解决，转人工」→ 填写标题 → 提交工单。

---

## 3. 历史与工单（40 秒）

1. 进入「咨询历史」：
   - 方式筛选「多轮」；
   - 关键词输入 `校园网`；
   - 打开「正则模式」，输入 `^校园网.*失败$`，展示正则筛选；
   - 点「查看」打开会话详情；
   - 点「导出 CSV」，用 Excel 打开（展示文件操作）。
2. 进入「我的工单」，指出刚提交的工单，状态「待处理」。

---

## 4. 管理端（2 分钟）

退出，用 `admin / admin123` 登录。

### 数据看板（40 秒）

- 指出 4 个 KPI、7 日趋势、方式占比、满意度、工单状态、热门主题。
- 说明图表是原生 Canvas 绘制，不依赖 CDN。

### 用户管理（30 秒）

- 点「新增用户」创建 `test01 / 123456`，角色「客服专员」；
- 或编辑 `teacher` 的角色，演示保存后侧边栏菜单变化。

### 日志管理（40 秒）

- 展示级别统计、列表；
- 关键词输入 `chat\..*`，打开「正则模式」→ 只剩咨询日志；
- 下拉到「今日日志文件（尾部 30 行）」，说明数据库 + 文件双写；
- 点「导出日志」。

### 工单管理（30 秒）

- 找到刚才的工单 → 状态改为「处理中」→ 更新；
- 回到用户端「我的工单」刷新，状态同步变化。

---

## 5. 创新点收尾（40 秒）

按四点讲：

1. **知识库检索增强**：检索 Top3 注入 Prompt，并在界面展示依据，降低幻觉；
2. **情绪识别**：输入「我要投诉，太差了」→ 回答先安抚，并提示转人工；
3. **工单闭环**：对话 → 工单 → 后台处理 → 用户端状态同步；
4. **离线可用**：星火不可用时自动降级本地引擎，演示不中断。

---

## 6. 可能被问到的问题

| 问题 | 回答要点 |
| --- | --- |
| 星火真的调用了吗？ | 客户端按官方 WebSocket 协议实现（鉴权、握手、帧解析），本机已实测可连通讯飞接口并通过 TLS 证书校验；配置密钥即走真实接口，未配置密钥时默认本地演示引擎，失败自动降级。 |
| 为什么用 MySQL？ | 本机用 XAMPP 自带 MySQL/MariaDB，`app/config.local.php` 里一行 `driver` 切换；同一套 PDO 代码也支持 SQLite 零配置（已实测两种模式）。 |
| 正则用在哪？ | 用户名/邮箱校验、日志与历史检索、手机号/邮箱/身份证脱敏、转人工意图识别。 |
| 权限怎么做的？ | Session + 角色矩阵；页面和 API 双重校验；越权写日志。 |
| 创新点是什么？ | 检索增强 + 情绪预警 + 工单闭环 + 离线降级（四点）。 |
| 数据是假的吗？ | 演示数据是脚本生成的 7 天模拟会话；所有交互（提问、评价、工单、日志）都是真实写入数据库的。 |
